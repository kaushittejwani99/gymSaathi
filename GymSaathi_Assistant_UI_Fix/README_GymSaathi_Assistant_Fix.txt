GymSaathi Assistant fixes

This patch fixes two issues seen on the Assistant page:
1) The question "किसकी फीस बाकी है?" is answered using the app's local member records, not generated by Gemini. Only members with a positive due amount are listed; if no member owes money, the answer says so.
2) Assistant and user chat bubbles size to their text rather than stretching vertically. The message text is trimmed and the stylesheet/app script URLs have a cache-busting version.

Files in this patch map to your repo:
- public/app.js
- public/styles.css
- public/index.html
- lib/ai.js

Install safely:
1. Back up those four files first.
2. Extract this ZIP into your repository root, allowing the four files above to be replaced.
3. Run:
   node --check public/app.js
   node --check lib/ai.js
4. Commit and push (if your deploy branch is main):
   git add public/app.js public/styles.css public/index.html lib/ai.js
   git commit -m "Fix assistant fee list and chat bubbles"
   git push origin main
5. Wait for Render to finish deploying, then hard refresh the site with Ctrl+Shift+R.

No database files or environment variables are included. A local test with one partially-paid member and two zero-due members passed: only the partially-paid member appeared. A separate test with no positive dues correctly returned "किसी की फीस बाकी नहीं है।" Live Render behaviour still needs to be checked after deployment.
